# app-movil

App Android nativa en Java (Android Studio). Se crea con *New Project → Empty Views Activity*:

- **Name:** GestionEstres
- **Package name:** com.ucentral.gestionestres.app
- **Save location:** esta carpeta (`app-movil`)
- **Language:** Java
- **Minimum SDK:** API 28 (Android 9), versión mínima de Health Connect (HU008)
- **Build configuration language:** Groovy DSL o Kotlin DSL

Desde el emulador, el backend local se llama con `http://10.0.2.2:8080`.
